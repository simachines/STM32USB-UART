# STM32F401 USB-UART Bridge — Flashing Guide

This firmware turns the STM32F401 into a **USB-to-UART bridge** between a PC
(Virtual COM Port) and an ESP32 (USART1). It is flashed **over USB** using the
chip's built-in DFU bootloader — **no ST-Link required**.

## Toolchain
No change needed. The project is generated by STM32CubeMX and builds with
**IAR EWARM** (`EWARM/` folder). The C code is toolchain-agnostic, so it also
builds in STM32CubeIDE or PlatformIO if you prefer.

## How USB DFU flashing works
The STM32F401 has a ROM bootloader in system memory that enumerates as a
**DFU** device over USB. To use it:

1. **Enter DFU mode**: set **BOOT0 = 1** (high) and press **RESET**.
   - The PC should now show a "STM32 BOOTLOADER" / DFU device.
2. **Flash** the firmware (see scripts below).
3. **Run**: set **BOOT0 = 0** and press **RESET** — your firmware boots.

## Prerequisites
- **STM32CubeProgrammer** installed (provides `STM32_Programmer_CLI`).
  - Windows: `C:\Program Files\STMicroelectronics\STM32Cube\STM32CubeProgrammer\bin\`
  - Linux/macOS: install via ST website, or use `dfu-util` instead.
- Build the project once in IAR so the `.hex` exists at:
  `EWARM/STM32F401 USB-UART Bridge PAssthrough/Exe/`

## Flash scripts
| Platform | Script |
|----------|--------|
| Windows  | `scripts\flash_dfu.bat` |
| Linux/macOS | `scripts/flash_dfu.sh` |

Both scripts:
1. Check the DFU device is present on USB.
2. Flash the `.hex` over USB DFU.
3. Verify and reset.

> **Note:** The `.bat` script hardcodes the CubeProgrammer path — edit the
> `CUBEPROG` variable if your install is elsewhere.

## Manual commands (if you prefer)
```bash
# STM32CubeProgrammer
STM32_Programmer_CLI -c port=usb -w "EWARM/.../Exe/....hex" -v -rst

# dfu-util (Linux/macOS)
dfu-util -a 0 -s 0x08000000:leave -D "EWARM/.../Exe/....hex"
```

## CubeMX settings to verify
- **USB_OTG_FS** clock = **48 MHz** (from HSE) — required for the CDC VCP to
  enumerate. The DFU bootloader works regardless (it's in ROM), but your VCP
  won't show up if the USB clock is wrong.
- **USB_DEVICE → CDC** enabled.
- **USART1**: RX DMA = `DMA2_Stream2` **Circular**, TX DMA = `DMA2_Stream7`
  **Normal** (both byte-aligned, memory increment on).
